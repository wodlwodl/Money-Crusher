
# 💰 Money Crusher

**Money Crusher** is a fun, fast-paced clicking game.
Break targets, earn coins, unlock new levels, and buy powerful tools!

## 🎮 How to Play

1. Press the **START** button.
2. Click or tap the **HIT!** button to break the target.
3. Earn coins for every hit.
4. Break the target before the timer reaches zero.
5. Clear levels to earn bonus coins and unlock the next level.

## 🏆 Levels

| Level | Target | Hits Needed |
|---|---|---:|
| 1 | 🐷 Piggy Bank | 5 |
| 2 | 👛 Mom's Wallet | 6 |
| 3 | 👝 Dad's Wallet | 7 |
| 4 | 🗄️ Teacher's Desk | 8 |
| 5 | 🔐 Safe | 9 |
| 6 | 🏦 Big Safe | 10 |
| 7 | 🏛️ Bank | 12 |
| 8 | 💼 My Wallet | 999 |

- Levels 1–7 have a 30-second time limit.
- Level 8 has a 1-second time limit and is designed to be almost impossible!

## 💰 Coins and Rewards

- Every hit: **+10 coins**
- Level 1 reward: 300 coins
- Level 2 reward: 400 coins
- Level 3 reward: 500 coins
- Level 6 reward: 600 coins

Other levels also give bonus coins when cleared.

## 🖥️ How to Run

Open `index.html` in a modern web browser, or publish the repository with GitHub Pages:

1. Push the repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Open the Pages URL shown in Settings after the deployment completes.

The game is a static site and does not require a build step or server. Coin and level progress is stored in the browser's local storage on the player's device.
